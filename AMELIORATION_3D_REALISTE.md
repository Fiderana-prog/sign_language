# Amélioration du rendu 3D réaliste

Cette version conserve les 20 animations `WORD_*` et améliore le rendu :

- matériau peau physique plus naturel ;
- couleur peau chaude ;
- réflexion et brillance modérées ;
- environnement de studio ;
- éclairage chaud, remplissage et contour ;
- ombres douces ;
- plan d'ombre discret ;
- cadrage automatique conservé.

La forme anatomique reste celle du mesh fourni. Pour un rendu
photoréaliste, il faudra plus tard remplacer le mesh par un modèle
de mains haute résolution compatible avec le même squelette.
